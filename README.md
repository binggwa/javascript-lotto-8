# javascript-lotto-precourse
## 구현할 기능 목록
### 입력 기능
- 로또 구입 금액 입력받기
  - 1,000원 단위로 입력되었는지 검증
- 당첨 번호를 입력받기
  - 당첨 번호가 1에서 45 사이인지 검증
  - 당첨 번호가 모두 다른지 검증
- 보너스 번호를 입력받기
  - 보너스 번호가 1에서 45 사이인지 검증
  - 보너스 번호가 당첨 번호와 겹치지 않는지 검증
### 출력 기능
- 발행한 로또 수량 및 번호 출력하기
  - 'n개를 구매했습니다' 출력하기
  - 로또 번호를 오름차순으로 정렬하여 출력하기
- 당첨 내역 출력하기
  - 5등부터 1등까지 차례대로 출력하기
  - '당첨 통계'
  - '---'
  - '3개 일치 (5,000원) - `5등 로또 개수`개'
  - '4개 일치 (50,000원) - `4등 로또 개수`개'
  - '5개 일치 (1,500,000원) - `3등 로또 개수`개'
  - '5개 일치, 보너스 볼 일치 (30,000,000원) - `2등 로또 개수`개'
  - '6개 일치 (2,000,000,000원) - `1등 로또 개수`개'
- 총 수익률 출력하기
  - 소수점 둘째 자리에서 반올림해서 출력하기
  - '총 수익률은 `수익률`%입니다.'
