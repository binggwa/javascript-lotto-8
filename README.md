# javascript-lotto-precourse
## 구현할 기능 목록
### 입력 기능 ( ConsoleInput )
- 로또 구입 금액 입력받기 ( readPurchasePrice )
  - 공백 여부 확인
  - 숫자 여부 확인
  - 최소 금액 이상인지 검증
  - 1,000원 단위로 입력되었는지 검증
- 당첨 번호를 입력받기 ( readWinningNumbers )
  - 쉼표로 파싱, 공백 제거
  - 당첨 번호가 총 6개의 숫자인지 검증
  - 당첨 번호가 1에서 45 사이인지 검증
  - 당첨 번호가 모두 다른지 검증
- 보너스 번호를 입력받기 ( readBonusNumber )
  - 보너스 번호가 1에서 45 사이인지 검증
  - 보너스 번호가 당첨 번호와 겹치지 않는지 검증
### 출력 기능 ( ConsoleOutput )
- 발행한 로또 수량 및 번호 출력하기 ( purchasePrice / 1000 )
  - 'n개를 구매했습니다' 출력하기
  - 로또 번호를 오름차순으로 정렬하여 출력하기
- 당첨 내역 출력하기 ( printStatistics(rankCounts) )
  - 5등부터 1등까지 차례대로 출력하기
  - '당첨 통계'
  - '---'
  - '3개 일치 (5,000원) - `5등 로또 개수: rankCounts[4]`개'
  - '4개 일치 (50,000원) - `4등 로또 개수: rankCounts[3]`개'
  - '5개 일치 (1,500,000원) - `3등 로또 개수: rankCounts[2]`개'
  - '5개 일치, 보너스 볼 일치 (30,000,000원) - `2등 로또 개수: rankCounts[1]`개'
  - '6개 일치 (2,000,000,000원) - `1등 로또 개수: rankCounts[0]`개'
- 총 수익률 출력하기 ( printTotalReturn )
  - 소수점 둘째 자리에서 반올림해서 출력하기
  - '총 수익률은 `수익률`%입니다.'
### 로또 ( Lotto )
- 생성자로 유효성 검증
  - 6개의 로또번호로 이루어져 있는지 검증
  - 번호가 1~45 범위에 있는지 검증
  - 번호가 중복되지 않는지 검증
- getNumbers()를 통한 번호 조회
### 로또 발행 ( LottoCompany )
- 구입 금액을 구입 최소 금액으로 나눈만큼 로또 발행 ( issueLottos )
- 랜덤 번호 생성
  - Random.pickUniqueNumbersInRange를 이용해 랜덤 번호 추출
  - sort로 오름차순 정렬
- 당첨 번호 입력받아서 세팅
  - setWinningNumbers
- 보너스 번호 입력받아서 세팅
  - setBonusNumber
- 등수 집계 ( getMatchedCounts )
  - 번호 일치 갯수에 따라 등수 카운팅
    - 1등 : 6개 일치
    - 2등 : 5개 일치 + 보너스 번호 일치
    - 3등 : 5개 일치
    - 4등 : 4개 일치
    - 5등 : 3개 일치
  - [1등, 2등, 3등, 4등, 5등] 의 배열로 반환
- 총 당첨금 계산 ( getTotalPrize )
  - [2,000,000,000, 30,000,000, 1,500,000, 50,000, 5,000] 의 등수별 상금 배열과 곱한 뒤 계산
### 로또 구매자 ( LottoBuyer )
- 구입 금액 보유, 회사에서 로또 구매 ( buyLottos )
- 보유 로또 조회 ( getLottos )
- 수익률 계산 ( getProfitRate )
  - (총 당첨금 / 구입 금액) * 100
  - 소숫점 둘째 자리에서 반올림
### 실행 흐름 ( App )
1. 구입 금액 입력/검증
2. 로또 구매
3. 구매내역 출력
4. 당첨 번호, 보너스 번호 입력/검증
5. 당첨 결과 집계 및 출력
6. 총 당첨금/수익률 계산 및 출력
